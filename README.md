# HackAiThon-_group-no_13 Project

# Learn for all- Inclusive Learning progress and Resource planner
A simple Python application that helps students learn better by identifying their strengths and weaknesses and suggesting what to study next.

# Project overview
Many students struggle because classroom teaching is the same for everyone, even though each student learns differently. Some students need more support, while others need more challenging content.

At the same time, students often don’t know what to study next or where they are going wrong. This leads to confusion, low confidence, and slow progress.

Our project aims to solve this by providing a simple system that evaluates learning and gives personalized guidance.

# What this project does

 This project does the following 

Takes a short test to check the student’s understanding

Analyzes performance automatically

Identifies strong and weak areas

Suggests what the student should study next and provide resources for the weak topics found

# Key features

Supports students from multiple classes (1–10)

Automatic result analysis

Topic-wise strength and weakness detection

Personalized study recommendations

Simple and easy-to-use interface

# Technologies used

## Tkinter
